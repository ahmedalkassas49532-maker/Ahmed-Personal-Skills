## How to use

Each `SKILL.md` is a reusable instruction file. To use one, provide its contents to an AI assistant or place it in a platform's supported skills directory/loader. **Adding files to this GitHub repository does not by itself install or activate them in ChatGPT or Claude.** Platform-specific setup is still required.

## Principles

- Prefer reliable, current, primary sources and provide links/citations for factual claims.
- Distinguish verified facts, estimates, assumptions, and opinions.
- Match explanations to the learner's level; teach rather than simply taking over.
- For student projects, prioritize safe, legal, low-voltage, supervised prototyping.
- Never invent sources, results, credentials, or completed actions.
